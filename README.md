# Mohammed Alfatih Osman Abdalsalam

**PhD candidate in Information and Communication Technology, Gdańsk University of Technology** · University Lecturer, University of the Holy Quran and Islamic Sciences (Sudan)

I work on multi-objective evolutionary optimisation and high-performance computing for ship weather routing, machine-learning surrogates of ship-performance simulation, and language technology for low-resource Arabic, especially Sudanese Arabic.

[Website](https://mohammed-abdalsalam-pg.github.io) · [Publications](https://mohammed-abdalsalam-pg.github.io/publications/) · [ORCID](https://orcid.org/0000-0001-9729-2609) · [Email](mailto:mohammed.abdalsalam@pg.edu.pl)

## Research software

| Project | What it is | Status |
|---|---|---|
| [PMOO — parallel multi-objective optimisation](https://github.com/MOHAMMED-ABDALSALAM-PG/PMOO-V1) | Serial, OpenMP, CUDA and hybrid CPU–GPU implementations of NSGA-II, SPEA2 and MOEA/D, benchmarked on ZDT/DTLZ problems and a physics-based heat-conduction problem. | Under consideration |
| [S175 ship-performance surrogate](https://github.com/MOHAMMED-ABDALSALAM-PG/S175-ML-surrogate) | Neural surrogate of the S175 WeatherRouting ship-performance simulator: nine operating and environmental inputs map to ten speed, fuel and seakeeping outputs. | Under consideration |
| [HPC for ship weather routing — systematic review](https://github.com/MOHAMMED-ABDALSALAM-PG/SWR-HPC-systematic-review) | Reproducibility package for a PRISMA 2020 systematic review of high-performance computing in multi-objective ship weather routing: protocol, executed queries per database, deduplication logs, screening decisions, extraction tables, evidence matrix and keyword maps, all generated by scripts. | Under consideration |
| [Sudanese Arabic harmful-language detection](https://github.com/scander91/sudanese-hate-speech-detection) | End-to-end pipeline for Sudanese Arabic harmful-language detection: text normalisation and de-duplication, weak-supervision label aggregation, transformer, BiLSTM, distillation and multi-task models, validation-only model selection, statistical evaluation and SHAP/LIME explanations. | Accepted subject to revision — IAENG IJCS |
| [Sudanese dialect identification: BERT vs LLMs](https://github.com/scander91/arabic-dialect-BERT-LLM) | Experiment code comparing fine-tuned Arabic BERT models with zero- and few-shot large language models for Sudanese Arabic dialect identification, in binary and 18-dialect settings on the QADI and NADI corpora. | Accepted, in production — DTRA |
| [MSF-CBERT — multi-source event classification](https://github.com/scander91/MSF-CBERT) | Multi-source fusion for attack-type classification on the Global Terrorism Database: a ConfliBERT encoder over event narratives, verbalised categorical attributes and a gated dense branch over numeric attributes, with an optional inductive event graph. | Research code |
| [Heterogeneous data fusion for event attribution](https://github.com/scander91/Intelligent-Fusion-of-Heterogeneous-Data-for-Terrorist-Organization) | Multi-modal preprocessing of the Global Terrorism Database (geocoding, Bayesian and distribution-aware imputation, redundancy analysis), silver-standard named-entity recognition and fine-tuned attribution classifiers, with robustness, generalisation and efficiency analyses. | Under consideration |

NLP repositories are on my second account, [scander91](https://github.com/scander91).
